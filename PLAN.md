# 200-City Prebuilt World Plan

## Outcome

Create, verify, and publish 200 detailed, downloadable city packages before runtime. This file is the table of contents; every linked phase file is an isolated implementation plan with its own steps, deliverables, assertions, and completion criteria.

## Execution rules

- Execute Phases 1–200 as independent city workstreams. Each must produce real loadable terrain and city artifacts; catalog entries and preview coordinates do not count.
- Prefer an approved official or licensed downloadable city model. Use hybrid completion when coverage is partial and deterministic procedural generation when no redistributable model exists.
- Phase 201 is the portfolio gate. It orchestrates all city builds, validates runtime behavior and performance, publishes immutable artifacts atomically, and requires `200/200` cities passing.
- Treat each phase file as authoritative for that phase. Do not rely on unstated steps from another phase.
- Run `pnpm plan:check` after changing this index or any phase file.

## Status convention

- `cataloged`: location and scope exist, but no city package is available.
- `built`: reproducible local artifacts exist but have not passed publication gates.
- `blocked`: lawful sources or required release evidence are unavailable.
- `published`: immutable artifacts and all required data, visual, traversal, streaming, and hardware-performance evidence pass.
