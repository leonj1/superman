# Dar es Salaam package

Phase 119 is a fail-closed acquisition and build contract, not a published city.

Creation mode: **procedural**. Named districts, landmarks, geography, water, bridges, airports, and transit scope are preserved in the recipe. Hero bounds are planning estimates pending authoritative validation.

Validation:

- node cities/dar-es-salaam/verify-preflight.mjs
- pnpm city:verify --city dar-es-salaam --profile catalog
- pnpm city:verify --city dar-es-salaam --profile release

The first two must pass. Release verification must fail until real hashes, artifacts, evidence, signatures, approvals, and physical-GPU certification exist.
