# Cape Town package

Phase 101 is a fail-closed acquisition and build contract, not a published city.

Creation mode: **hybrid**. Named districts, landmarks, geography, water, bridges, airports, and transit scope are preserved in the recipe. Hero bounds are planning estimates pending authoritative validation.

Validation:

- node cities/cape-town/verify-preflight.mjs
- pnpm city:verify --city cape-town --profile catalog
- pnpm city:verify --city cape-town --profile release

The first two must pass. Release verification must fail until real hashes, artifacts, evidence, signatures, approvals, and physical-GPU certification exist.
