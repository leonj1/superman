# Warsaw package

Phase 054 is a fail-closed acquisition and build contract, not a published city.

Creation mode: **hybrid**. The recipe preserves the phase-specific districts, landmarks, geography, water, bridges, airports, transit, and build scope. Hero bounds are planning estimates pending authoritative validation.

Validation:

- node cities/warsaw/verify-preflight.mjs
- pnpm city:verify --city warsaw --profile catalog
- pnpm city:verify --city warsaw --profile release

The first two must pass. Release must fail until real hashes, artifacts, evidence, signatures, approvals, and physical-GPU certification exist.
