# Brussels package

Phase 050 is a fail-closed acquisition and build contract, not a published city.

Creation mode: **procedural**. The recipe preserves the phase-specific districts, landmarks, geography, water, bridges, airports, transit, and build scope. Hero bounds are planning estimates pending authoritative validation.

Validation:

- node cities/brussels/verify-preflight.mjs
- pnpm city:verify --city brussels --profile catalog
- pnpm city:verify --city brussels --profile release

The first two must pass. Release must fail until real hashes, artifacts, evidence, signatures, approvals, and physical-GPU certification exist.
